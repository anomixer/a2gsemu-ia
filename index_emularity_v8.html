    🎮 MAME 模擬器操作

    📋 基本控制

    • Scroll Lock 開啟/關閉 MAME UI 模式
    • Tab 開啟 MAME 選單
    • ~ (波浪號) 快速選單
    • P 暫停模擬器
    • F4 顯示調色盤
    • F8 降低幀率跳過
    • F9 提高幀率跳過

    ⚙️ Machine Configuration

    先按 Scroll Lock 開啟 UI → 再按 Tab → 選擇 Machine Configuration

    • CPU Speed: 調整 CPU 執行速度
      可加速慢速遊戲或減速過快遊戲
    • Video Options: 視訊設定
      調整畫面大小、濾鏡效果
    • Audio Options: 音訊設定
      音量、取樣率調整
    • Input Settings: 輸入設定
      自訂按鍵配置

    💾 存檔/讀檔

    • Shift+F7 存檔到當前槽位
    • F7 從當前槽位讀檔
    • 支援多個存檔槽位 (0-9)

    ℹ️ 關於 Apple IIgs

    Apple IIgs 是 Apple Computer 於 1986 年 9 月推出的 16 位元個人電腦,是 Apple II 系列的最後一款產品。

    主要規格:

    • 2.8 MHz 的 65C816 處理器
    • 256 KB RAM (可擴充至 8 MB)
    • 支援 4096 色顯示
    • Ensoniq 5503 音效晶片 (32 聲道)
    • 向下相容 Apple II 系列軟體
